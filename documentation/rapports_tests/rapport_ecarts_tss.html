Lecture & seuils recommandés

  • Le RPE sous-estime presque partout aux intensités tempo/seuil : le barème de Friel (entier) crédite un cran de RPE un peu moins que l'IF² réel de la méthode physiologique.
  • vs hrTSS (FC) : 7.6 % — meilleur accord. L'endurance tombe pile (RPE 4 ≈ IF 0,70).
  • vs puissance (vélo) : 9.1 % — bon accord, même profil que la FC.
  • vs rTSS (course) : 15.9 % — le plus mauvais, car le rTSS majore de ×110 (surcoût course) que le RPE n'intègre pas. Conseil : préférer l'allure ou la FC à la course ; n'utiliser le RPE qu'en dernier recours.
  • Seuil d'acceptation conseillé pour le RPE : ≤ 20 %. Toutes les valeurs y restent (max 21.1 % en course tempo, à la limite). Au-delà, l'écart vient d'un sport mal adapté au RPE, pas d'un bug.
  • Lissage : ces écarts par séance sont absorbés par la CTL/ATL (moyennes mobiles 42 j / 7 j) — impact faible sur les tendances de charge.

Méthodologie : référence = TSS de la bonne méthode par sport (tss puissance, rtss allure, hrtss FC) à IF fixé (0,70 / 0,83 / 0,95) ; comparaison = rpe (table de Friel, RPE 4 / 5 / 7). Mesure réelle end-to-end via Playwright : 12 séances (3 puissance + 3 allure + 3 FC + 3 RPE) créées dans le formulaire de création manuelle de l'app, le TSS étant celui écrit en base par le code de production. Valeurs lues : puissance 49 / 69 / 91 (tss), allure 54 / 76 / 99 (rtss), FC 50 / 68 / 90 (hrtss), RPE 50 / 60 / 80 (rpe) — conformes au moteur. Les 6 sports FC (marche, rando, ski alpin, ski de fond, renfo, autre) partagent la branche hrtss : résultats identiques, la marche servant de représentant testé. Séances de test supprimées et seuils temporaires retirés après mesure.
